# 711 Black Gold - 헬다이버즈 2 클랜 홍보 사이트

GitHub Pages로 바로 배포되는 정적 사이트입니다.

## 배포 방법
1. GitHub에서 새 저장소 생성 (Public)
2. `index.html`, `README.md` 업로드 (Add file → Upload files)
3. Settings → Pages → Branch: `main` / `/ (root)` → Save
4. 1~2분 뒤 `https://내아이디.github.io/저장소이름/` 에서 확인

## 수정
- 디스코드 링크: `index.html` 하단 `DISCORD_URL` 에 초대 링크 입력
